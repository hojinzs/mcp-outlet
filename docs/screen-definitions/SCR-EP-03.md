# SCR-EP-03 MCP 상세

| 항목     | 내용                                           |
| -------- | ---------------------------------------------- |
| 경로     | `/admin/endpoints/:id`                         |
| 권한     | MCP 소유자 (admin도 다른 사람 것은 볼 수 없음) |
| 우선순위 | P0                                             |
| 요구사항 | F-CON-04, F-CON-05, F-EP-02, F-EP-03, F-EP-04  |

## 목적

MCP 하나의 노출 툴, 이름, 활성 상태를 바꾸고, 필요 없으면 지운다. 이 MCP가 쓰는 서버의 접속 정보도 여기서 고친다. 서버만 따로 관리하는 화면은 두지 않는다.

## 구성

### 머리

| 요소      | 내용                                         |
| --------- | -------------------------------------------- |
| 이름      | 연필 버튼으로 그 자리에서 편집. Enter로 저장 |
| 상태 배지 | SCR-EP-01의 상태 규칙과 같음                 |
| 연결 안내 | SCR-EP-04로 이동                             |

### 기본 정보

| 항목     | 내용                                                         |
| -------- | ------------------------------------------------------------ |
| MCP 주소 | 전체 주소와 복사 버튼                                        |
| 서버     | 서버 이름과 종류. MCP를 만든 뒤에는 다른 서버로 바꿀 수 없다 |
| 만든 날  | 날짜·시각                                                    |

### 서버 접속 정보

이 MCP가 쓰는 서버의 설정이다. 같은 서버를 쓰는 MCP가 여러 개면 위에 "이 서버를 쓰는 MCP N개에 함께 적용됩니다"를 표시한다.

| 요소                  | 원격 MCP 서버                               | 내장 서비스                                                                                                         |
| --------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 주소·서비스           | 서버 주소(편집 가능)                        | 서비스 이름(바꿀 수 없음)                                                                                           |
| 접속 정보             | 토큰: "설정됨 · {변경 시각}"과 교체 버튼    | 연결된 계정(예: `steve@daniworks.kr`)·연결 시각, 다시 연결·다른 계정으로 바꾸기. 서비스 계정이면 이메일과 파일 교체 |
| 연결 테스트           | 버튼과 마지막 결과. 성공하면 툴 목록을 갱신 | 같음                                                                                                                |
| 이 서버로 MCP 하나 더 | SCR-EP-02로 이동(`?connector={id}`)         | 같음                                                                                                                |

- 주소나 토큰을 바꾸면 저장 전에 연결 테스트를 다시 해야 한다. 실패하면 저장하지 않는다.
- 연결 테스트 실패 분류와 문구는 SCR-EP-02의 연결 테스트와 같다.
- 재연결은 SCR-EP-02의 계정 연결과 같은 업스트림 동의를 거친다. 돌아오면 이 화면으로 온다.

### 노출 툴

SCR-EP-02 2단계와 같은 툴 선택 목록을 쓴다. 다른 점은 다음과 같다.

| 요소            | 내용                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------- |
| 새 툴           | 허용목록을 정한 뒤 서버에 생긴 툴은 목록 위에 "새 툴" 묶음으로 따로 보여준다. 선택 안 된 상태 |
| 새 툴 확인함    | 새 툴을 허용하지 않고 배지만 없앤다. 허용목록은 그대로 두고 `knownTools`만 갱신한다           |
| 사라진 툴       | 허용목록에 있지만 서버 툴 목록에 없는 이름. "서버에서 사라짐" 표시와 함께 목록 끝에 둔다      |
| 저장 / 되돌리기 | 바뀐 것이 있을 때만 활성. 저장 전에는 호출에 반영되지 않는다                                  |

- 사라진 툴은 호출해도 업스트림이 거부하므로 해가 없다. 저장할 때 자동으로 빼지 않고, 사용자가 지울 수 있게 체크를 풀어 둔 상태로 보여준다.
- 허용 툴을 0개로 저장할 수는 없다. 다 막고 싶으면 비활성을 쓰라고 안내한다.

### 상태

| 요소        | 내용                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| 활성 스위치 | 바꾸면 바로 저장한다. 다음 MCP 요청부터 반영(F-EP-04)                            |
| 설명        | 끄면 이 URL로 오는 요청을 거부합니다. AI 클라이언트의 연결 설정은 그대로 둡니다. |

### 삭제

화면 맨 아래 따로 둔다.

- 삭제 버튼을 누르면 확인 창을 띄운다. "삭제하면 이 주소로 다시 연결할 수 없습니다. 같은 설정이 필요하면 새로 만들어야 하고 주소도 바뀝니다."
- 이 서버를 쓰는 마지막 MCP면 확인 창에 "서버와 접속 정보도 함께 지우기"를 체크된 상태로 둔다. 체크를 풀면 서버를 남겨 두었다가 다음 MCP 추가 때 "내 서버에서 고르기"로 다시 쓸 수 있다.
- 확인하면 지우고 목록(SCR-EP-01)으로 간다. 감사 로그의 기록은 남는다(MCP 칸만 비워짐).

## 동작

- 저장하지 않은 툴 변경이 있는데 화면을 떠나면 확인을 띄운다.
- 다른 사람의 엔드포인트 ID로 들어오면 404로 처리한다. 존재 여부를 알려주지 않기 위해서다(F-AUTH-05).

## 필요한 API (안)

| 메서드 | 경로                              | 내용                                                                    |
| ------ | --------------------------------- | ----------------------------------------------------------------------- |
| GET    | `/api/endpoints/:id`              | 엔드포인트와 커넥터 툴 목록, 새 툴·사라진 툴 구분                       |
| PATCH  | `/api/endpoints/:id`              | `name`, `allowedTools`, `enabled`, `acknowledgeNewTools` 중 바꾼 것만   |
| DELETE | `/api/endpoints/:id`              | 삭제. `deleteConnector=true`면 마지막 MCP일 때 서버도 삭제              |
| GET    | `/api/connectors/:id`             | 서버 설정, 접속 정보 설정 여부·변경 시각, 연결된 계정, 이 서버의 MCP 수 |
| PATCH  | `/api/connectors/:id`             | 주소·토큰 교체. 서버가 연결 테스트를 통과해야 저장                      |
| POST   | `/api/connectors/:id/test`        | 연결 테스트, 툴 목록 캐시 갱신                                          |
| POST   | `/api/connectors/:id/oauth/start` | 재연결·계정 바꾸기용 업스트림 동의 주소                                 |

## 결정 사항

- **새 툴 판별 (2026-11-04)**: `endpoints`에 `knownTools`(text[]) 컬럼을 추가한다. 허용목록을 저장하거나 "새 툴 확인함"을 누를 때 그 시점 서버의 툴 이름 전체를 저장한다. 새 툴은 `현재 서버 툴 − knownTools`다. 목록 화면(SCR-EP-01)의 "새 툴 N" 배지도 같은 값을 쓴다. 새 툴은 사용자가 허용하기 전에는 노출되지 않는다.
