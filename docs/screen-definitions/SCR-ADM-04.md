# SCR-ADM-04 사용자 목록

| 항목     | 내용                  |
| -------- | --------------------- |
| 경로     | `/admin/manage/users` |
| 권한     | admin                 |
| 우선순위 | P1                    |
| 요구사항 | F-UI-02               |

## 목적

누가 MCP Outlet을 쓰는지 보고, 사용자가 등록한 커넥터 중 문제가 있는 것을 찾아 사용 중지한다. 사용자가 아무 원격 MCP 서버나 등록할 수 있기 때문에 관리자가 확인할 곳이 필요하다.

## 구성

### 머리

| 요소 | 내용                                    |
| ---- | --------------------------------------- |
| 제목 | 사용자                                  |
| 검색 | 이메일로 거르기                         |
| 필터 | 전체 / 사용 중지한 커넥터가 있는 사용자 |

### 사용자 목록

| 열            | 내용                                               |
| ------------- | -------------------------------------------------- |
| 이메일        | IdP `email` 클레임. 없으면 `sub` 앞부분            |
| 역할          | user / admin 배지                                  |
| 그룹          | IdP 그룹 칩. 마지막 로그인이나 MCP 요청 때 받은 값 |
| 마지막 로그인 | 날짜·시각                                          |
| 커넥터        | 커넥터 수. 사용 중지한 것이 있으면 "중지 N" 배지   |
| 엔드포인트    | 엔드포인트 수                                      |
| 최근 호출     | 이 사용자의 엔드포인트 중 가장 최근 `lastCalledAt` |

- 정렬은 최근 호출순. 호출이 없는 사용자는 마지막 로그인순으로 뒤에 둔다.
- 역할과 그룹은 IdP가 정하므로 이 화면에서 바꿀 수 없다. 사용자를 막으려면 Authentik에서 그룹을 빼라고 안내한다.

### 사용자 펼치기: 커넥터 목록

행을 누르면 그 아래에 그 사람의 커넥터를 펼친다.

| 열         | 내용                                                                        |
| ---------- | --------------------------------------------------------------------------- |
| 이름       | 커넥터 이름                                                                 |
| 종류       | 원격 MCP / 내장 서비스 이름                                                 |
| 원격 URL   | 원격 MCP면 주소. 쿼리 문자열의 값과 사용자 정보(`user:pass@`)는 가려서 표시 |
| 상태       | 정상 / 오류 / 재연결 필요 / 사용 중지됨                                     |
| 엔드포인트 | 이 커넥터를 쓰는 엔드포인트 수                                              |
| 최근 호출  | 커넥터의 `lastCalledAt`                                                     |
| 사용 중지  | 버튼. 사용 중지된 커넥터면 "다시 사용"과 중지 사유·시각·중지한 관리자       |

- 자격증명 값, 토큰 설정 여부 외의 정보, 툴 허용목록은 보여주지 않는다. 관리자가 볼 필요가 있는 것은 "어디에 붙었는지"까지다.
- 내장 서비스는 연결된 계정 이메일도 보여주지 않는다. 사용자 개인 계정 정보라서다.

## 사용 중지

- 버튼을 누르면 확인 창을 띄운다. 사유 입력란(필수, 200자 이내)과 영향 문구를 둔다. "이 커넥터의 엔드포인트 N개가 바로 호출을 거부합니다. 사용자는 엔드포인트 목록에서 사유를 볼 수 있습니다."
- 확인하면 다음 MCP 요청부터 거부한다. 사용자의 엔드포인트 목록(SCR-EP-01)에는 "사용 중지됨"과 사유가 보인다.
- 사용 중지된 커넥터는 사용자가 설정을 바꿔도 다시 켜지지 않는다. 관리자가 "다시 사용"을 눌러야 한다.
- 사용자는 사용 중지된 커넥터를 지울 수 있다. 지우면 그 기록도 사라진다.

## 동작

- 사용자가 100명을 넘을 일은 드물어서 목록은 한 번에 불러오고, 커넥터 목록은 펼칠 때 불러온다.
- 사용 중지·다시 사용은 작업 기록(`activity_logs`)에 남긴다(누가, 언제, 어떤 커넥터, 사유). v1에는 작업 기록 전용 화면이 없고, 커넥터 행에 마지막 중지 정보만 보여준다.
- 그룹 정보는 관리 UI 로그인과 MCP 요청 때마다 토큰 값으로 갱신된다. MCP만 쓰는 사용자도 최신 그룹이 보인다.

## 필요한 API (안)

| 메서드 | 경로                              | 내용                                                         |
| ------ | --------------------------------- | ------------------------------------------------------------ |
| GET    | `/api/admin/users`                | 사용자 목록과 수치(커넥터·엔드포인트 수, 중지 수, 최근 호출) |
| GET    | `/api/admin/users/:id/connectors` | 그 사용자의 커넥터. 원격 URL은 서버에서 가려서 내려준다      |
| PATCH  | `/api/admin/connectors/:id`       | `{ disabled: true, reason }` / `{ disabled: false }`         |

## 결정 사항

- **관리자 작업 기록 위치 (2026-11-04)**: 감사 로그와 따로 `activity_logs`(시각, 행위자, 작업, 대상 종류·ID, 사유)에 남긴다. Client Secret 보기 기록도 같은 곳에 둔다. 보관은 기본 365일(`ACTIVITY_RETENTION_DAYS`).
- **그룹에서 빠진 사용자 (2026-11-04)**: MCP 요청마다 토큰의 groups로 로그인 허용 그룹을 다시 확인해 거부한다(PRD F-AUTH-06). 늦어도 access token 수명(30분) 안에 반영된다. 운영 문서에는 Authentik 앱 정책으로 토큰 발급 자체를 막는 설정을 함께 권장한다.
