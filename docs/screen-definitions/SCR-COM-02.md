# SCR-COM-02 로그인 시작

| 항목     | 내용                    |
| -------- | ----------------------- |
| 경로     | `/admin/login`          |
| 권한     | 누구나 (로그인 전 화면) |
| 우선순위 | P0                      |
| 요구사항 | F-AUTH-01, F-AUTH-02    |

## 목적

세션이 없는 사용자를 IdP 로그인으로 보낸다. 로그인이 실패했을 때 이유를 보여준다.

## 진입

- 세션 없이 `/admin/` 아래 어느 화면에 들어온 경우. 원래 가려던 경로를 `returnTo`로 받는다.
- 로그아웃한 직후
- 로그인 콜백(`/auth/callback`)이 실패해 `error`를 붙여 돌려보낸 경우

## 구성

| 요소        | 내용                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| 제품 이름   | "MCP Outlet"과 한 줄 설명                                                       |
| 로그인 버튼 | "로그인". 누르면 `/auth/login?returnTo=…`로 이동해 IdP 로그인 화면으로 넘어간다 |
| 오류 문구   | `error`가 있을 때만 버튼 위에 표시                                              |

IdP 이름(Authentik 등)은 버튼에 넣지 않는다. IdP를 바꿔도 화면을 고치지 않게 하기 위해서다(F-AUTH-01).

## 동작

- 이미 세션이 있으면 이 화면을 보여주지 않고 `returnTo` 또는 홈으로 보낸다.
- 자동으로 IdP로 넘기지 않고 버튼을 누르게 한다. 로그인 실패가 반복될 때 화면이 IdP와 오가며 무한 반복하지 않게 하기 위해서다.
- `returnTo`는 `/admin/`으로 시작하는 경로만 받는다. 다른 값이면 버린다(외부 주소로 보내는 오픈 리다이렉트 방지).
- PKCE·state·nonce는 gateway의 `/auth/login`과 `/auth/callback`이 처리한다. 화면은 값을 다루지 않는다.

## 오류 문구

| `error` 값       | 문구                                                      |
| ---------------- | --------------------------------------------------------- |
| `access_denied`  | 로그인을 취소했습니다. 다시 시도하세요.                   |
| `state_mismatch` | 로그인 요청이 만료됐습니다. 다시 시도하세요.              |
| `idp_error`      | 로그인 서버에서 오류가 났습니다. 잠시 후 다시 시도하세요. |
| 그 밖의 값       | 로그인하지 못했습니다. 다시 시도하세요.                   |

IdP가 돌려준 오류 원문(`error_description`)은 보여주지 않는다.

## 필요한 API (안)

| 메서드 | 경로             | 내용                                                                                           |
| ------ | ---------------- | ---------------------------------------------------------------------------------------------- |
| GET    | `/auth/login`    | PKCE·state를 만들고 IdP authorize로 리다이렉트                                                 |
| GET    | `/auth/callback` | 코드를 토큰으로 교환하고 세션을 만든 뒤 `returnTo`로 리다이렉트. 허용 그룹이 아니면 SCR-COM-03 |
