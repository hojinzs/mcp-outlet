# SCR-COM-03 접근 거부

| 항목     | 내용               |
| -------- | ------------------ |
| 경로     | `/admin/forbidden` |
| 권한     | 누구나             |
| 우선순위 | P0                 |
| 요구사항 | F-AUTH-06          |

## 목적

IdP 로그인은 됐지만 이 화면을 쓸 권한이 없을 때, 이유와 다음 행동을 알려준다.

## 진입

| 경우                    | `reason`     | 세션                                 |
| ----------------------- | ------------ | ------------------------------------ |
| 로그인 허용 그룹이 아님 | `not_member` | 만들지 않는다                        |
| user가 관리 화면 진입   | `admin_only` | 유지. 레이아웃(SCR-COM-01) 안에 표시 |

## 구성

| 요소 | `not_member`                                                                                    | `admin_only`                                                                  |
| ---- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 제목 | 사용 권한이 없습니다                                                                            | 관리자만 볼 수 있는 화면입니다                                                |
| 설명 | `{이메일}` 계정은 MCP Outlet 사용 그룹에 속해 있지 않습니다. 관리자에게 그룹 추가를 요청하세요. | admin 역할이 필요하면 관리자에게 로그인 서비스(IdP)의 그룹 추가를 요청하세요. |
| 버튼 | 다른 계정으로 로그인                                                                            | 홈으로                                                                        |

- 이메일은 IdP 토큰의 `email` 클레임을 그대로 보여준다. 주소에 싣지 않고, 화면이 세션 없이 `GET /auth/denied`로 `{ email }`을 받는다(아래 결정 사항). 응답(실패 포함)을 받기 전에는 화면을 그리지 않아 문구가 바뀌며 깜빡이지 않게 한다. `email`이 null이거나 요청이 실패하면 "이 계정은 MCP Outlet 사용 그룹에 속해 있지 않습니다. …"로 보인다.
- 그룹 이름 목록(`OIDC_LOGIN_GROUPS`, `OIDC_ADMIN_GROUPS`)은 보여주지 않는다. 내부 조직 구조를 드러내지 않기 위해서다.

## 동작

- **다른 계정으로 로그인**: IdP 세션이 그대로면 같은 계정으로 다시 로그인된다. 그래서 레이아웃(SCR-COM-01)의 같은 이름 메뉴와 똑같이 IdP 로그아웃(end_session)을 거쳐 SCR-COM-02로 돌아오게 한다.
- `not_member`는 세션을 만들지 않으므로, 이 화면에서 새로고침해도 다른 화면으로 넘어가지 않는다.
- 그룹이 추가된 뒤에는 다시 로그인하면 바로 들어올 수 있다(groups는 로그인마다 갱신).

## 결정 사항

- **IdP 로그아웃 주소 (2026-11-04)**: OIDC discovery의 `end_session_endpoint`를 쓴다. discovery에 이 값이 없는 IdP면 "다른 계정으로 로그인" 버튼을 숨기고 IdP에서 직접 로그아웃하라고 안내한다. 지원 여부는 세션 없이 읽는 `GET /auth/options`의 `idpLogout`으로 받고, 레이아웃(SCR-COM-01) 계정 메뉴의 같은 항목도 숨긴다 (2026-11-05).
- **거부 이메일 전달 (2026-11-06)**: `/auth/callback`은 그룹 밖 로그인을 `/admin/forbidden?reason=not_member`로만 보내고, 이메일은 `SESSION_SECRET`으로 서명한 HttpOnly 쿠키 `outlet_denied`(수명 10분, `Path=/auth/denied`)에 담는다. 주소에 실으면 리버스 프록시 접근 로그·브라우저 기록에 남고 아무 값이나 넣어 보여줄 수 있기 때문이다. `GET /auth/denied`는 이 쿠키를 읽어 `{ email }`을 주고, 쿠키가 없거나 만료·위조면 `null`이다. 이메일 없이 거부되거나 로그인에 성공하면 이전 쿠키를 지운다.
