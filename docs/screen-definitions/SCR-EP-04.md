# SCR-EP-04 연결 안내

| 항목     | 내용                                                  |
| -------- | ----------------------------------------------------- |
| 경로     | `/admin/endpoints/:id/connect`                        |
| 권한     | 엔드포인트 소유자 (admin도 다른 사람 것은 볼 수 없음) |
| 우선순위 | P0                                                    |
| 요구사항 | F-EP-05, F-AUTH-04, F-AUTH-05                         |

## 목적

엔드포인트를 Claude·ChatGPT·Claude Code에 등록하는 데 필요한 값과 절차를 한 화면에 모아 준다. 엔드포인트를 만든 직후 이 화면으로 온다.

## 구성

### 연결 값

| 항목           | 값                             | 표시                               |
| -------------- | ------------------------------ | ---------------------------------- |
| 엔드포인트 URL | `{PUBLIC_BASE_URL}/c/{id}/mcp` | 그대로, 복사 버튼                  |
| Client ID      | `OIDC_CLIENT_ID`               | 그대로, 복사 버튼                  |
| Client Secret  | `OIDC_CLIENT_SECRET`           | 가려서 표시. 보기 버튼과 복사 버튼 |

- 만든 직후 진입이면 위에 "엔드포인트를 만들었습니다" 안내를 띄운다.
- Client Secret이 설정되지 않은 설치(Public client)면 이 줄을 숨긴다.
- callback 주소는 사용자가 입력할 값이 아니라서 보여주지 않는다. 관리자가 IdP에 미리 등록해 둔다(README의 IdP 설정).

### 등록 절차

클라이언트별 탭으로 나눈다. 탭 순서는 Claude, ChatGPT, Claude Code.

| 탭          | 절차 요지                                                                                                                          |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Claude      | 설정 → 커넥터 → 커스텀 커넥터 추가. 이름과 서버 URL 입력, 고급 설정에 Client ID·Secret 입력 → 추가 → 연결 → IdP 로그인             |
| ChatGPT     | 설정에서 Developer mode 켜기 → 커넥터 만들기. 서버 URL 입력, 인증은 OAuth, Client ID·Secret 입력 → IdP 로그인                      |
| Claude Code | `claude mcp add`로 HTTP 서버 추가. 서버 URL과 Client ID·Secret을 넣은 명령을 복사 버튼과 함께 보여준다. 첫 호출 때 브라우저 로그인 |

- 각 탭 끝에 "연결이 되면 이 엔드포인트에서 고른 툴 N개가 보입니다"를 넣는다.
- 클라이언트 메뉴 이름과 Claude Code 명령은 자주 바뀐다. 구현할 때 현재 화면과 명령을 확인해 문구를 맞추고, 안내 하단에 확인한 날짜를 적는다.

### 문제 해결

접어 둔 영역으로 둔다.

| 증상                        | 안내                                                                                   |
| --------------------------- | -------------------------------------------------------------------------------------- |
| 로그인 후 "권한 없음"       | MCP Outlet 사용 그룹에 속해 있는지 관리자에게 확인                                     |
| 연결은 되는데 툴이 안 보임  | 엔드포인트가 비활성인지, 노출 툴을 골랐는지 확인. 상세 화면 링크                       |
| 다른 사람에게 주소를 공유함 | 엔드포인트는 만든 사람 계정으로만 호출된다. 각자 엔드포인트를 만들어야 한다(F-AUTH-05) |

## 동작

- 값은 `GET /api/endpoints/:id/connect-info`로 받는다. Client Secret은 보기·복사 버튼을 눌렀을 때만 따로 요청하고, 요청할 때마다 누가 언제 봤는지 기록한다(값은 기록하지 않음).
- 복사하면 토스트로 "복사했습니다"를 띄운다.

## 필요한 API (안)

| 메서드 | 경로                              | 내용                                     |
| ------ | --------------------------------- | ---------------------------------------- |
| GET    | `/api/endpoints/:id/connect-info` | 커넥터 URL, Client ID, secret 존재 여부  |
| GET    | `/api/connect-secret`             | Client Secret. 요청을 감사 목적으로 기록 |

## 결정 사항

- **Client Secret 공유 (2026-11-04)**: Confidential client를 유지하고 모든 사용자에게 같은 secret을 보여준다. secret을 알아도 허용된 계정으로 IdP에 로그인해야 토큰을 받고, 엔드포인트 소유자 검사(F-AUTH-05)로 다른 사람의 엔드포인트는 쓸 수 없다. 대신 다음을 둔다.
  - secret 보기·복사 요청을 기록한다.
  - secret을 바꾸면 연결된 모든 클라이언트에 다시 입력해야 한다. 회전 절차(IdP에서 재발급 → `OIDC_CLIENT_SECRET` 교체 → 재시작 → 사용자 공지)를 운영 문서에 둔다.
  - 고객사 설치 전에 자체 인가 서버(DCR·CIMD)로 공유 secret을 없애는 방안을 다시 본다(PRD 범위 밖과 v2 과제).
