# SCR-EP-01 내 엔드포인트 목록

| 항목     | 내용             |
| -------- | ---------------- |
| 경로     | `/admin/` (홈)   |
| 권한     | user·admin       |
| 우선순위 | P0               |
| 요구사항 | F-EP-01, F-UI-01 |

## 목적

내가 만든 엔드포인트를 한눈에 보고, URL을 복사하거나 연결 안내로 바로 가게 한다. 로그인 후 처음 보는 화면이다.

## 구성

| 영역 | 요소          | 내용             |
| ---- | ------------- | ---------------- |
| 머리 | 제목          | 내 엔드포인트    |
|      | 새 엔드포인트 | SCR-EP-02로 이동 |
| 목록 | 엔드포인트 행 | 아래 표의 열     |

목록 열은 다음과 같다.

| 열      | 내용                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| 이름    | 누르면 SCR-EP-03                                                                     |
| 커넥터  | 커넥터 이름과 런타임 배지(remote / builtin / stdio)                                  |
| 노출 툴 | `허용 수 / 커넥터 전체 툴 수`. 커넥터에 새 툴이 생겼으면 "새 툴 N" 배지              |
| 상태    | 활성 / 비활성 / 자격증명 필요 / 커넥터 사용 불가. 우선순위는 아래 상태 규칙을 따른다 |
| URL     | `/c/{id}/mcp` 전체 주소를 줄여 보여주고 복사 버튼                                    |
| 작업    | 연결 안내(SCR-EP-04)                                                                 |

## 상태 규칙

한 행에 상태 하나만 표시한다. 위에 있는 것이 먼저다.

| 상태             | 조건                                                            | 뜻                                        |
| ---------------- | --------------------------------------------------------------- | ----------------------------------------- |
| 커넥터 사용 불가 | 커넥터가 더 이상 나에게 공개되지 않음(공개 그룹 변경)           | 호출이 거부된다. 관리자에게 문의          |
| 자격증명 필요    | 커넥터에 user 범위 자격증명 필드가 있는데 내 값이 없거나 만료됨 | 호출이 실패한다. 내 자격증명(P1)에서 입력 |
| 비활성           | `enabled = false`                                               | 내가 꺼 둔 상태                           |
| 활성             | 그 밖                                                           |                                           |

P0의 CMS 커넥터는 global 자격증명만 써서 "자격증명 필요"는 나오지 않는다.

## 동작

- 정렬은 최근 수정순. 엔드포인트가 20개를 넘을 일은 드물어서 페이지 나눔과 검색은 두지 않는다.
- URL 복사는 `PUBLIC_BASE_URL` 기준 전체 주소를 클립보드에 넣고 "복사했습니다" 토스트를 띄운다.
- 상태 토글과 삭제는 이 화면에 두지 않는다. 실수로 끄거나 지우지 않도록 상세 화면(SCR-EP-03)에서만 한다.

## 빈 상태

엔드포인트가 하나도 없으면 목록 대신 안내를 보여준다.

- 제목: 아직 엔드포인트가 없습니다
- 설명: 커넥터 하나를 골라 Claude·ChatGPT에 붙일 URL을 만드세요. 필요한 툴만 골라 노출할 수 있습니다.
- 버튼: 첫 엔드포인트 만들기 → SCR-EP-02
- 볼 수 있는 커넥터도 없으면 버튼 대신 "사용할 수 있는 커넥터가 없습니다. 관리자에게 문의하세요."
