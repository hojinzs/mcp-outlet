# SCR-EP-01 엔드포인트 목록

| 항목     | 내용             |
| -------- | ---------------- |
| 경로     | `/admin/` (홈)   |
| 권한     | user·admin       |
| 우선순위 | P0               |
| 요구사항 | F-EP-01, F-UI-01 |

## 목적

내가 만든 엔드포인트를 한눈에 보고, 엔드포인트 URL을 복사하거나 연결 안내로 바로 가게 한다. 고쳐야 할 것(커넥터 오류, 재연결 필요)을 여기서 알아챈다. 로그인 후 처음 보는 화면이다.

## 구성

| 영역 | 요소            | 내용                               |
| ---- | --------------- | ---------------------------------- |
| 머리 | 제목            | 내 엔드포인트                      |
|      | 엔드포인트 추가 | SCR-EP-02로 이동                   |
| 알림 | 배너            | 재연결이 필요한 커넥터가 있을 때만 |
| 목록 | 엔드포인트 행   | 아래 표의 열                       |

목록 열은 다음과 같다.

| 열             | 내용                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 이름           | 누르면 SCR-EP-03                                                        |
| 커넥터         | 커넥터 이름과 종류(원격 MCP / 내장 서비스 이름)                         |
| 노출 툴        | `허용 수 / 커넥터 전체 툴 수`. 커넥터에 새 툴이 생겼으면 "새 툴 N" 배지 |
| 상태           | 아래 상태 규칙                                                          |
| 엔드포인트 URL | `/c/{id}/mcp` 전체 주소를 줄여 보여주고 복사 버튼                       |
| 작업           | 연결 안내(SCR-EP-04)                                                    |

- "새 툴 N"은 커넥터 툴 목록(툴 캐시) 기준이다. 툴 캐시는 연결 테스트로 갱신되고, 원격 커넥터는 AI 클라이언트가 보낸 `tools/list`가 프록시를 지날 때도 갱신된다(PRD "툴 캐시 갱신").

## 상태 규칙

한 행에 상태 하나만 표시한다. 위에 있는 것이 먼저다.

| 상태        | 조건                                                       | 뜻                                                         |
| ----------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 사용 중지됨 | 관리자가 이 커넥터를 사용 중지함                           | 호출이 거부된다. 관리자에게 문의                           |
| 재연결 필요 | 내장 서비스의 OAuth 계정 연결이 만료됐거나 갱신이 거부됨   | 호출이 실패한다. 엔드포인트 상세에서 다시 연결             |
| 커넥터 오류 | 마지막 호출이나 연결 테스트에서 인증 실패·연결 실패가 났음 | 토큰이나 주소가 바뀌었을 수 있다. 엔드포인트 상세에서 확인 |
| 비활성      | `enabled = false`                                          | 내가 꺼 둔 상태                                            |
| 활성        | 그 밖                                                      |                                                            |

같은 커넥터를 쓰는 엔드포인트는 "재연결 필요"와 "커넥터 오류"를 함께 표시한다. 커넥터 하나를 고치면 그 커넥터의 엔드포인트가 모두 풀린다.

서비스 계정 커넥터는 다시 연결할 것이 없어 상태 배지의 안내(툴팁, 상세 화면 머리의 설명)를 바꾼다. 서비스 계정 키가 거부되면 커넥터 오류가 된다(PRD "서비스 계정 키 거부").

| 상태        | 서비스 계정 커넥터의 안내                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| 커넥터 오류 | 서비스 계정 키가 거부되었을 수 있습니다. 엔드포인트 상세에서 연결 테스트를 하고, 거부되면 키 파일을 교체하세요.       |
| 재연결 필요 | 호출이 실패합니다. 엔드포인트 상세에서 서비스 계정 키 파일을 교체하세요. (키 거부를 재연결 필요로 남기던 이전 커넥터) |

`/api/endpoints`는 커넥터 인증 방식을 주지 않으므로 화면은 커넥터 목록(`/api/connectors`)에서 인증 방식을 찾는다. 커넥터 목록을 받기 전에는 기본 안내를 쓴다.

## 알림 배너

재연결이 필요한 커넥터가 하나라도 있으면 목록 위에 띄운다. "Google Analytics 연결이 끊겨 엔드포인트 2개가 동작하지 않습니다. 다시 연결하세요." 버튼은 그 커넥터를 쓰는 첫 엔드포인트의 상세로 간다.

재연결 필요인 서비스 계정 커넥터(이전 커넥터)는 "{커넥터 이름}의 서비스 계정 키가 거부되어 엔드포인트 N개가 동작하지 않습니다. 키 파일을 교체하세요."와 "키 파일 교체" 버튼으로 바꿔 보인다. 버튼이 가는 곳은 같다.

## 동작

- 정렬은 최근 수정순. 엔드포인트가 20개를 넘을 일은 드물어서 페이지 나눔과 검색은 두지 않는다.
- 주소 복사는 `PUBLIC_BASE_URL` 기준 전체 주소를 클립보드에 넣고 "복사했습니다" 토스트를 띄운다.
- 상태 토글과 삭제는 이 화면에 두지 않는다. 실수로 끄거나 지우지 않도록 상세 화면(SCR-EP-03)에서만 한다.
- **계정 연결 결과 안내**: 업스트림 동의 콜백이 돌아갈 화면을 모르면(state 쿠키가 만료됐거나 맞지 않음) gateway는 홈으로 `?connect_error=expired|failed`를 붙여 보낸다. 홈은 목록 위에 오류색으로 안내한다. `expired`는 "계정 연결 시간(10분)이 지나 연결을 마치지 못했습니다. 엔드포인트 상세나 추가 화면에서 다시 연결하세요", 그 밖의 `connect_error`는 "계정 연결을 마치지 못했습니다. 엔드포인트 상세나 추가 화면에서 다시 연결하세요"다. 어느 커넥터인지 모르므로 다시 연결할 곳을 함께 알린다. 처음 한 번만 읽고 쿼리에서 `connect_error`를 지워 새로고침해도 다시 뜨지 않는다.

## 빈 상태

엔드포인트가 하나도 없으면 목록 대신 안내를 보여준다.

- 제목: 아직 엔드포인트가 없습니다
- 설명: 쓰고 있는 MCP 서버 주소나 Google Analytics 같은 서비스를 등록하고, AI에 보여줄 툴만 골라 주소를 받으세요.
- 버튼: 첫 엔드포인트 추가 → SCR-EP-02

## 필요한 API (안)

| 메서드 | 경로             | 내용                                                                     |
| ------ | ---------------- | ------------------------------------------------------------------------ |
| GET    | `/api/endpoints` | 엔드포인트 목록. 커넥터 이름·종류, 툴 수, 새 툴 수, 상태를 계산해서 준다 |

## 결정 사항

- **엔드포인트 없는 커넥터 (2026-11-05)**: 엔드포인트를 지울 때 커넥터를 남겨 두면 사용자당 커넥터 상한을 차지한다. 목록 아래에 "엔드포인트 없는 커넥터" 묶음(이름, 종류, 상태 배지, 삭제 버튼)을 그런 커넥터가 있을 때만 보여준다. 삭제 확인은 SCR-EP-03의 커넥터 삭제와 같은 창을 쓴다. 정상 커넥터는 SCR-EP-02의 "내 커넥터에서 고르기"로 다시 쓴다. 정상이 아닌(연결 중·커넥터 오류·재연결 필요) 커넥터는 "다시 연결·연결 테스트" 링크로 SCR-EP-02의 이어하기 화면(`?connector={id}`)에 가서 고친 뒤 쓴다. 관리자가 사용 중지한 커넥터는 링크 없이 배지만 보인다.
