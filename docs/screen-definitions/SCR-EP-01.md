# SCR-EP-01 엔드포인트 목록

| 항목     | 내용             |
| -------- | ---------------- |
| 경로     | `/admin/` (홈)   |
| 권한     | user·admin       |
| 우선순위 | P0               |
| 요구사항 | F-EP-01, F-UI-01 |

## 목적

내가 만든 엔드포인트를 한눈에 보고, 엔드포인트 URL을 복사하거나 연결 안내로 바로 가게 한다. 고쳐야 할 것(커넥터 오류, 재연결 필요)을 여기서 알아챈다. 로그인 후 처음 보는 화면이다.

## 구성

| 영역 | 요소            | 내용                               |
| ---- | --------------- | ---------------------------------- |
| 머리 | 제목            | 내 엔드포인트                      |
|      | 엔드포인트 추가 | SCR-EP-02로 이동                   |
| 알림 | 배너            | 재연결이 필요한 커넥터가 있을 때만 |
| 목록 | 엔드포인트 행   | 아래 표의 열                       |

목록 열은 다음과 같다.

| 열             | 내용                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 이름           | 누르면 SCR-EP-03                                                        |
| 커넥터         | 커넥터 이름과 종류(원격 MCP / 내장 서비스 이름)                         |
| 노출 툴        | `허용 수 / 커넥터 전체 툴 수`. 커넥터에 새 툴이 생겼으면 "새 툴 N" 배지 |
| 상태           | 아래 상태 규칙                                                          |
| 엔드포인트 URL | `/c/{id}/mcp` 전체 주소를 줄여 보여주고 복사 버튼                       |
| 작업           | 연결 안내(SCR-EP-04)                                                    |

## 상태 규칙

한 행에 상태 하나만 표시한다. 위에 있는 것이 먼저다.

| 상태        | 조건                                                       | 뜻                                                         |
| ----------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 사용 중지됨 | 관리자가 이 커넥터를 사용 중지함                           | 호출이 거부된다. 관리자에게 문의                           |
| 재연결 필요 | 내장 서비스의 계정 연결이 만료됐거나 갱신에 실패함         | 호출이 실패한다. 엔드포인트 상세에서 다시 연결             |
| 커넥터 오류 | 마지막 호출이나 연결 테스트에서 인증 실패·연결 실패가 났음 | 토큰이나 주소가 바뀌었을 수 있다. 엔드포인트 상세에서 확인 |
| 비활성      | `enabled = false`                                          | 내가 꺼 둔 상태                                            |
| 활성        | 그 밖                                                      |                                                            |

같은 커넥터를 쓰는 엔드포인트는 "재연결 필요"와 "커넥터 오류"를 함께 표시한다. 커넥터 하나를 고치면 그 커넥터의 엔드포인트가 모두 풀린다.

## 알림 배너

재연결이 필요한 커넥터가 하나라도 있으면 목록 위에 띄운다. "Google Analytics 연결이 끊겨 엔드포인트 2개가 동작하지 않습니다. 다시 연결하세요." 버튼은 그 커넥터를 쓰는 첫 엔드포인트의 상세로 간다.

## 동작

- 정렬은 최근 수정순. 엔드포인트가 20개를 넘을 일은 드물어서 페이지 나눔과 검색은 두지 않는다.
- 주소 복사는 `PUBLIC_BASE_URL` 기준 전체 주소를 클립보드에 넣고 "복사했습니다" 토스트를 띄운다.
- 상태 토글과 삭제는 이 화면에 두지 않는다. 실수로 끄거나 지우지 않도록 상세 화면(SCR-EP-03)에서만 한다.

## 빈 상태

엔드포인트가 하나도 없으면 목록 대신 안내를 보여준다.

- 제목: 아직 엔드포인트가 없습니다
- 설명: 쓰고 있는 MCP 서버 주소나 Google Analytics 같은 서비스를 등록하고, AI에 보여줄 툴만 골라 주소를 받으세요.
- 버튼: 첫 엔드포인트 추가 → SCR-EP-02
