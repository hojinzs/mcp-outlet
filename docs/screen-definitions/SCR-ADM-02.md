# SCR-ADM-02 커넥터 만들기·편집

| 항목     | 내용                                                                |
| -------- | ------------------------------------------------------------------- |
| 경로     | `/admin/manage/connectors/new`, `/admin/manage/connectors/:id/edit` |
| 권한     | admin                                                               |
| 우선순위 | P0                                                                  |
| 요구사항 | F-CON-01, F-CON-02, F-CON-03, F-CON-07, F-RUN-05                    |

## 목적

전역 커넥터의 정의(매니페스트)를 폼이나 YAML로 만들고 고친다. 자격증명 값은 여기서 받지 않고 커넥터 상세(SCR-ADM-03)에서 받는다. 정의와 비밀값을 한 화면에 섞지 않기 위해서다.

## 구성

폼 탭과 YAML 탭이 같은 매니페스트를 다룬다. 탭을 바꾸면 내용이 그대로 옮겨진다.

### 폼 탭

**기본**

| 필드      | 매니페스트 키   | 규칙                                                                                               |
| --------- | --------------- | -------------------------------------------------------------------------------------------------- |
| 이름      | `name`          | 필수                                                                                               |
| 설명      | `description`   | 선택. 사용자가 커넥터를 고를 때 보인다                                                             |
| 공개 그룹 | `visibleGroups` | 칩 입력. 지금까지 로그인한 사용자의 그룹을 후보로 보여주고, 직접 입력도 받는다. 비우면 모든 사용자 |

**런타임과 실행 정보**

런타임은 만들 때만 고를 수 있고, 저장한 뒤에는 바꿀 수 없다. 바꾸려면 새 커넥터를 만든다.

| 런타임  | 필드                                                       | 규칙                                                                    |
| ------- | ---------------------------------------------------------- | ----------------------------------------------------------------------- |
| remote  | 원격 MCP URL (`url`)                                       | https 주소. 로컬 개발용 http loopback만 예외                            |
| builtin | 내장 커넥터 (`builtin`)                                    | gateway에 등록된 내장 커넥터 키 중에서 선택                             |
| stdio   | 레지스트리(npm / PyPI), 패키지 이름, 버전, 실행 명령, 인자 | 버전은 정확한 버전만(`1.2.3`). 실행 명령을 비우면 패키지 기본 실행 파일 |

**자격증명 스키마** (F-CON-02)

필드를 행으로 추가·삭제한다.

| 열   | 키       | 규칙                                                              |
| ---- | -------- | ----------------------------------------------------------------- |
| 키   | `key`    | 영문·숫자·`_`, 숫자로 시작 불가. stdio에서는 환경변수 이름이 된다 |
| 라벨 | `label`  | 사용자·관리자가 입력할 때 보이는 이름                             |
| 비밀 | `secret` | 기본 켜짐. 켜면 입력 후 다시 보여주지 않는다                      |
| 범위 | `scope`  | global(관리자가 한 번 입력) / user(사용자마다 입력)               |

**업스트림 인증** (F-CON-03)

런타임에 따라 고를 수 있는 방식이 다르다.

| 방식        | 런타임          | 추가 필드                                                                               |
| ----------- | --------------- | --------------------------------------------------------------------------------------- |
| 없음        | 전부            | 없음                                                                                    |
| 정적 토큰   | remote, builtin | 토큰 필드(자격증명 키 중 선택), 헤더 이름(기본 `Authorization`), 접두어(기본 `Bearer `) |
| 환경변수    | stdio           | 없음. 자격증명 필드가 키 이름 그대로 환경변수로 들어간다                                |
| OAuth2      | remote, builtin | 인가 URL, 토큰 URL, scope 목록, Client ID 필드, Client Secret 필드(자격증명 키 중 선택) |
| 서비스 계정 | remote, builtin | JSON 필드(자격증명 키 중 선택)                                                          |

"자격증명 키 중 선택"은 위 스키마에 있는 키만 고를 수 있는 선택 상자다.

### YAML 탭

| 요소      | 내용                                              |
| --------- | ------------------------------------------------- |
| 편집기    | 매니페스트 YAML. 줄 번호와 오류 위치 표시         |
| 파일 열기 | `.yaml`·`.yml` 파일을 읽어 편집기에 넣는다        |
| 내려받기  | 현재 내용을 `{slug}.yaml`로 저장. 편집 화면에서만 |

YAML에는 자격증명 값이 들어가지 않는다. 가져오기·내보내기는 정의만 옮긴다.

## 검증

- 폼과 YAML 모두 `packages/shared`의 매니페스트 스키마로 검사한다. 서버도 같은 스키마로 다시 검사한다.
- 오류는 해당 필드 아래에 보여준다. YAML 탭에서는 오류 줄을 표시한다.
- 스키마가 막는 대표적인 경우: 중복 키, 인증이 없는 키를 참조, stdio에 정적 토큰 지정, remote에 환경변수 지정, 버전 범위(`^1.2.0`) 입력

## 저장

- 새로 만들면 커넥터 상세(SCR-ADM-03)로 간다. 상세에서 공용 자격증명 입력과 연결 테스트를 이어서 한다.
- 편집에서 다음을 바꾸면 저장 전에 확인 창으로 영향을 알린다.

| 바꾼 것                    | 영향                                                            |
| -------------------------- | --------------------------------------------------------------- |
| 자격증명 필드 삭제·키 변경 | 저장된 그 필드 값이 지워진다. 사용자 값 포함                    |
| 필드 범위 global ↔ user    | 저장된 그 필드 값이 지워지고 다시 입력해야 한다                 |
| 공개 그룹 축소             | 빠진 그룹 사용자의 엔드포인트 N개가 "커넥터 사용 불가"가 된다   |
| URL·패키지·버전·인증 방식  | 툴 목록 캐시를 지운다. 연결 테스트를 다시 해야 한다             |
| stdio 패키지·버전          | 저장하면 runner가 새 버전을 설치하고, 실행 중 프로세스를 끝낸다 |

## 필요한 API (안)

| 메서드 | 경로                           | 내용                                              |
| ------ | ------------------------------ | ------------------------------------------------- |
| GET    | `/api/admin/connectors/:id`    | 매니페스트                                        |
| POST   | `/api/admin/connectors`        | 매니페스트로 생성                                 |
| PUT    | `/api/admin/connectors/:id`    | 매니페스트 교체. 응답에 지워진 자격증명 필드 목록 |
| POST   | `/api/admin/connectors/impact` | 저장 전 영향 계산(엔드포인트 수, 지워질 값)       |
| GET    | `/api/admin/builtins`          | 등록된 내장 커넥터 키와 설명                      |
| GET    | `/api/admin/groups`            | 지금까지 로그인한 사용자의 그룹 목록              |

## 정할 것

- 공개 그룹 후보를 IdP에서 직접 가져오지 않고 로그인한 사용자의 그룹으로만 만든다. IdP 관리 API를 쓰면 Authentik 전용 코드가 생기기 때문이다(F-AUTH-01).
