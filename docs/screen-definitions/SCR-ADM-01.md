> **v2 화면.** PRD v0.2에서 관리자 전역 커넥터를 v2로 미뤘다(2026-11-04). v1에서는 만들지 않는다. 정의는 v2 작업 때 다시 맞춘다.

| 항목     | 내용                        |
| -------- | --------------------------- |
| 경로     | `/admin/manage/connectors`  |
| 권한     | admin                       |
| 우선순위 | P0                          |
| 요구사항 | F-CON-01, F-CON-07, F-UI-02 |

## 목적

전역 커넥터 전체를 보고, 설정이 덜 끝난 커넥터를 찾고, 새 커넥터를 만든다. 사용자의 개인 커넥터는 여기 나오지 않는다.

## 구성

| 영역 | 요소          | 내용                                        |
| ---- | ------------- | ------------------------------------------- |
| 머리 | 제목          | 커넥터 카탈로그                             |
|      | 새 커넥터     | SCR-ADM-02 (`/admin/manage/connectors/new`) |
|      | YAML 가져오기 | SCR-ADM-02를 YAML 탭이 열린 상태로 연다     |
| 필터 | 런타임        | 전체 / remote / builtin / stdio             |
|      | 준비 상태     | 전체 / 설정 필요만                          |
| 목록 | 커넥터 행     | 아래 표의 열                                |

| 열         | 내용                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| 이름       | 누르면 SCR-ADM-03                                                                                                      |
| 런타임     | 배지                                                                                                                   |
| 범위       | 공유(자격증명 필드가 모두 global이거나 없음) / 템플릿(user 필드가 하나 이상)                                           |
| 공개 그룹  | 그룹 이름 칩. 비어 있으면 "모든 사용자"                                                                                |
| 준비 상태  | 준비됨 / 설정 필요. 설정 필요면 이유를 함께: 공용 자격증명 없음, 연결 테스트 안 함, 연결 테스트 실패, 설치 실패(stdio) |
| 툴         | 캐시된 툴 수와 캐시 시각                                                                                               |
| 엔드포인트 | 이 커넥터로 만든 엔드포인트 수                                                                                         |

## 준비 상태 규칙

사용자가 엔드포인트를 만들 수 있으려면 툴 목록이 필요하다(SCR-EP-02). 그래서 다음을 모두 만족해야 "준비됨"이다.

1. global 범위 자격증명 필드가 있으면 값이 모두 입력돼 있다.
2. stdio면 패키지 설치가 끝났다.
3. 연결 테스트가 한 번 이상 성공해 툴 목록이 캐시돼 있다.

템플릿 커넥터는 사용자 값이 없어도 1번만 본다.

## 동작

- 정렬은 "설정 필요"를 위로, 그 안에서 이름순.
- 커넥터가 없으면 빈 상태로 "첫 커넥터를 만드세요"와 두 버튼(새 커넥터, YAML 가져오기)을 보여준다. `manifests/examples`의 예시를 가져오면 된다는 안내를 함께 둔다.
