# SCR-ADM-03 커넥터 상세

| 항목     | 내용                                   |
| -------- | -------------------------------------- |
| 경로     | `/admin/manage/connectors/:id`         |
| 권한     | admin                                  |
| 우선순위 | P0                                     |
| 요구사항 | F-CON-02, F-CON-06, F-CON-07, F-RUN-05 |

## 목적

커넥터를 쓸 수 있는 상태로 만든다. 공용 자격증명을 넣고, 연결 테스트로 툴 목록을 받고, stdio면 설치 상태를 확인한다.

## 구성

### 머리

| 요소          | 내용                                                    |
| ------------- | ------------------------------------------------------- |
| 이름·설명     | 매니페스트 값                                           |
| 배지          | 런타임, 범위(공유 / 템플릿), 준비 상태(SCR-ADM-01 규칙) |
| 편집          | SCR-ADM-02                                              |
| YAML 내보내기 | `{slug}.yaml` 내려받기                                  |
| 삭제          | 아래 삭제 참고                                          |

### 공용 자격증명

global 범위 필드만 보여준다. global 필드가 없으면 이 영역을 숨긴다.

| 요소      | 내용                                                                                         |
| --------- | -------------------------------------------------------------------------------------------- |
| 필드      | 라벨과 입력란. 비밀 필드는 비밀번호 입력란                                                   |
| 저장된 값 | 비밀 필드: "설정됨 · {변경 시각}"만 표시하고 값은 보여주지 않는다. 비밀이 아닌 필드: 값 표시 |
| 저장      | 입력한 필드만 바꾼다. 비워 둔 비밀 필드는 기존 값을 유지                                     |
| 값 지우기 | 필드별 버튼. 확인 후 지운다                                                                  |

- 저장한 값은 암호화해서 보관한다. 화면과 API 응답 어디에도 비밀 값을 다시 내보내지 않는다.
- 값을 바꾸면 툴 목록 캐시는 그대로 두고 "연결 테스트를 다시 해 보세요"를 띄운다.

### 연결 테스트 (F-CON-06)

| 요소        | 내용                                                                |
| ----------- | ------------------------------------------------------------------- |
| 테스트 버튼 | 업스트림에 `tools/list`를 보낸다. 실행 중에는 버튼을 막고 진행 표시 |
| 마지막 결과 | 성공 시각과 툴 수 / 실패 시각과 오류 요약                           |

- 실패 요약은 분류만 보여준다: 인증 실패(401·403), 주소에 연결할 수 없음, 시간 초과, MCP 응답 형식 오류, 설치 안 됨(stdio). 업스트림 응답 본문과 예외 원문은 보여주지 않는다(F-RUN-07).
- 성공하면 툴 목록 캐시를 새 결과로 바꾼다. 실패하면 이전 캐시를 그대로 둔다.
- 템플릿 커넥터는 관리자 본인의 user 자격증명으로 테스트한다. 관리자 값이 없으면 "내 자격증명을 먼저 입력하세요"를 보여준다.

### 툴 목록

| 열      | 내용                                                    |
| ------- | ------------------------------------------------------- |
| 이름    | 코드 글꼴                                               |
| 설명    | 첫 줄. 누르면 전체                                      |
| 힌트    | 읽기(`readOnlyHint`), 삭제·변경(`destructiveHint`) 배지 |
| 노출 수 | 이 툴을 허용한 엔드포인트 수                            |

캐시 시각을 표 위에 적는다. 캐시가 없으면 "연결 테스트를 하면 툴 목록이 채워집니다".

### 설치 상태 (stdio만)

| 상태    | 표시                                                                     |
| ------- | ------------------------------------------------------------------------ |
| 설치 중 | 진행 표시. 끝나면 자동으로 갱신                                          |
| 설치됨  | 패키지 이름·버전, 설치 시각                                              |
| 실패    | 실패 시각과 요약(패키지 없음, 버전 없음, 설치 명령 실패), 다시 설치 버튼 |

실행 중인 프로세스 수와 stdio 프로세스 화면(P1) 링크를 함께 둔다.

### 사용 현황

| 항목       | 내용                                             |
| ---------- | ------------------------------------------------ |
| 엔드포인트 | 이 커넥터로 만든 엔드포인트 수                   |
| 사용자     | 엔드포인트를 가진 사용자 수                      |
| 사용자 값  | 템플릿 커넥터면 user 자격증명을 입력한 사용자 수 |

### 삭제

- 확인 창에 영향을 보여준다: "엔드포인트 N개(사용자 M명)가 함께 삭제되고, 저장된 자격증명이 모두 지워집니다."
- 엔드포인트가 1개 이상이면 커넥터 이름을 입력해야 삭제 버튼이 켜진다.
- 삭제하면 카탈로그(SCR-ADM-01)로 간다. 감사 로그 기록은 남는다.

| 메서드 | 경로                                         | 내용                                                                  |
| ------ | -------------------------------------------- | --------------------------------------------------------------------- |
| GET    | `/api/admin/connectors/:id`                  | 매니페스트, 준비 상태, 자격증명 필드별 설정 여부·변경 시각, 사용 현황 |

| GET    | `/api/admin/connectors/:id/export`           | 매니페스트 YAML                                                       |
| POST   | `/api/admin/connectors/:id/install`          | stdio 다시 설치                                                       |
| DELETE | `/api/admin/connectors/:id`                  | 삭제                                                                  |
