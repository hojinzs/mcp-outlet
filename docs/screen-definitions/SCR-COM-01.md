# SCR-COM-01 레이아웃

| 항목     | 내용                                   |
| -------- | -------------------------------------- |
| 경로     | 로그인 이후 모든 화면의 바깥 틀        |
| 권한     | user·admin. 관리 메뉴는 admin만        |
| 우선순위 | P0                                     |
| 요구사항 | F-UI-01, F-UI-02, F-AUTH-02, F-AUTH-06 |

## 목적

어느 화면에서든 같은 메뉴로 이동하고, 지금 누구로 로그인했는지 확인하고, 로그아웃할 수 있게 한다.

## 구성

| 영역      | 요소      | 내용                                                                                                           |
| --------- | --------- | -------------------------------------------------------------------------------------------------------------- |
| 상단 바   | 제품 이름 | "MCP Outlet". 누르면 홈(SCR-EP-01)                                                                             |
|           | 계정 메뉴 | 이메일, 역할 배지(admin일 때만). 펼치면 로그아웃, 다른 계정으로 로그인(IdP가 로그아웃을 지원할 때만)           |
| 메뉴      | 내 작업   | 내 엔드포인트. 재연결 필요 엔드포인트가 있으면 메뉴 옆에 그 수를 배지로 표시                                   |
|           | 관리      | admin에게만 "관리" 묶음을 보여준다. v1은 사용자 목록·감사 로그(P1), v2에서 커넥터 카탈로그·stdio 프로세스 추가 |
| 본문      | 각 화면   | 화면 제목과 주요 버튼은 각 화면이 정한다                                                                       |
| 알림 영역 | 토스트    | 저장·복사·삭제 결과를 3초간 표시                                                                               |

- 아직 구현하지 않은 화면의 메뉴는 숨긴다. "준비 중" 메뉴를 두지 않는다.
- 현재 화면이 속한 메뉴를 강조한다.
- 좁은 화면(768px 미만)에서는 메뉴를 햄버거 버튼 뒤로 접는다.

## 동작

- **첫 진입**: `GET /api/me`로 사용자 정보와 역할을 받는다. 받기 전에는 메뉴 자리를 비워 두고 본문에 로딩 표시를 한다.
- **세션 만료**: 어떤 API든 401을 받으면 현재 경로를 `returnTo`로 붙여 로그인 시작(SCR-COM-02)으로 보낸다.
- **권한 부족**: 관리자 API가 403을 주면 접근 거부(SCR-COM-03)로 보낸다. 메뉴를 숨겨도 주소를 직접 입력할 수 있으므로 화면마다 막는다.
- **로그아웃**: `POST /auth/logout`으로 gateway 세션만 지우고 SCR-COM-02로 보낸다. IdP 세션은 그대로 둔다. 다른 사내 앱(Grafana 등)의 SSO 로그인을 끊지 않기 위해서다.
- **다른 계정으로 로그인**: `POST /auth/logout?idp=true`로 gateway 세션을 지운 뒤, IdP의 `end_session_endpoint`로 보내 IdP 세션까지 끝낸다. 돌아오는 곳은 SCR-COM-02다. 주소는 OIDC discovery에서 읽으므로 IdP 전용 코드가 없다.
- **역할 변경**: 역할은 관리 UI 로그인과 MCP 요청마다 groups 클레임으로 다시 정해진다(PRD F-AUTH-06). 로그인 중에 IdP 그룹이 바뀌면 그 사람의 다음 로그인이나 새 토큰으로 온 MCP 요청부터 반영된다.
- **재연결 배지**: 레이아웃이 `GET /api/endpoints`를 함께 읽어 상태가 재연결 필요인 엔드포인트 수를 "내 엔드포인트" 옆에 띄운다(화면 정의 목록의 재연결 알림). 커넥터 오류는 홈의 상태 표시로만 알린다.

## 필요한 API (안)

| 메서드 | 경로            | 내용                                                  |
| ------ | --------------- | ----------------------------------------------------- |
| GET    | `/api/me`       | `{ id, email, role, groups }`. 세션 없으면 401        |
| POST   | `/auth/logout`  | 세션 쿠키 삭제. `idp=true`면 IdP 로그아웃 주소를 응답 |
| GET    | `/auth/options` | `{ idpLogout }`. 세션 없이 받는다(SCR-COM-03)         |

## 결정 사항

- **IdP 세션 종료 (2026-11-04)**: 일반 로그아웃은 gateway 세션만 지우고, "다른 계정으로 로그인"만 IdP 세션까지 끝낸다(OIDC RP-initiated logout).
