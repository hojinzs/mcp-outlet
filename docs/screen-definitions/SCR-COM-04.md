# SCR-COM-04 오류·없는 화면

| 항목     | 내용                                       |
| -------- | ------------------------------------------ |
| 경로     | `/admin/*` 중 없는 경로, 화면 로딩 실패 시 |
| 권한     | 누구나                                     |
| 우선순위 | P1                                         |
| 요구사항 | F-RUN-03                                   |

## 목적

화면을 그릴 수 없을 때 무엇이 잘못됐고 무엇을 하면 되는지 알려준다. 오류 원문과 내부 정보는 보여주지 않는다.

## 표시 위치

오류를 어디에 보여줄지는 오류가 난 범위로 정한다.

| 범위                                   | 표시                                            |
| -------------------------------------- | ----------------------------------------------- |
| 화면 전체를 불러오지 못함              | 이 화면(레이아웃 안 본문 자리)                  |
| 저장·삭제·테스트 같은 동작 하나가 실패 | 그 동작 옆의 인라인 문구나 토스트. 이 화면 아님 |
| 세션 만료(401)                         | 이 화면 없이 로그인 시작(SCR-COM-02)으로        |
| 권한 부족(403)                         | 접근 거부(SCR-COM-03)                           |

## 종류별 문구

| 종류            | 조건                                               | 제목                       | 설명                                                                      | 버튼                |
| --------------- | -------------------------------------------------- | -------------------------- | ------------------------------------------------------------------------- | ------------------- |
| 없음 (404)      | 없는 경로, 없는 엔드포인트, 다른 사람의 엔드포인트 | 찾을 수 없습니다           | 주소가 바뀌었거나 삭제됐을 수 있습니다.                                   | 엔드포인트 목록으로 |
| 서버 오류 (5xx) | gateway가 오류를 돌려줌                            | 화면을 불러오지 못했습니다 | 잠시 후 다시 시도하세요. 계속되면 관리자에게 아래 요청 번호를 알려주세요. | 다시 시도, 홈으로   |
| 연결 끊김       | gateway에 닿지 않음(네트워크 오류, 응답 없음)      | 서버에 연결할 수 없습니다  | 인터넷 연결을 확인하고 다시 시도하세요.                                   | 다시 시도           |

- 다른 사람의 엔드포인트와 없는 엔드포인트를 같은 404로 보여준다. 존재 여부를 알려주지 않기 위해서다(F-AUTH-05).
- 서버 오류에는 요청 번호(gateway 로그의 `reqId`)를 작게 보여주고 복사 버튼을 둔다. 관리자가 로그에서 찾을 수 있게 하기 위해서다. 오류 메시지 원문, 스택, 업스트림 응답은 보여주지 않는다.
- 레이아웃(SCR-COM-01)은 그대로 둔다. 세션이 살아 있으면 메뉴로 다른 화면에 갈 수 있다.

## 동작

- **다시 시도**: 같은 화면의 데이터를 다시 요청한다. 연속으로 누르지 못하게 요청 중에는 버튼을 막는다.
- 연결 끊김은 브라우저가 다시 온라인이 되면(`online` 이벤트) 자동으로 한 번 다시 시도한다.

## 필요한 API (안)

없음. 모든 API 오류 응답은 `{ error: { code, message }, requestId }` 모양으로 맞춘다. `message`는 사용자에게 보여줘도 되는 고정 문구만 담는다.
