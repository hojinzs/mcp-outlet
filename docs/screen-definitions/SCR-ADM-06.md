# SCR-ADM-06 감사 로그

| 항목     | 내용                  |
| -------- | --------------------- |
| 경로     | `/admin/manage/audit` |
| 권한     | admin                 |
| 우선순위 | P1                    |
| 요구사항 | F-UI-02, F-UI-03      |

## 목적

누가 어떤 엔드포인트로 어떤 툴을 언제 불렀는지, 실패나 거부가 얼마나 있었는지 본다. 호출 내용(인자·응답 본문)은 저장하지 않으므로 여기에도 없다(F-UI-03).

## 구성

### 필터

| 필터       | 내용                                               |
| ---------- | -------------------------------------------------- |
| 기간       | 최근 1시간 / 24시간(기본) / 7일 / 30일 / 직접 지정 |
| 사용자     | 이메일 선택                                        |
| 엔드포인트 | 사용자를 고르면 그 사람의 엔드포인트 중에서 선택   |
| 결과       | 전체 / 성공 / 오류 / 거부                          |
| 툴 이름    | 이름 일부로 검색                                   |

필터는 주소(`location.search`)에 넣어 새로고침과 링크 공유가 되게 한다.

### 요약

필터 결과 위에 한 줄로 보여준다.

| 항목     | 내용                                                  |
| -------- | ----------------------------------------------------- |
| 호출     | 전체 호출 수                                          |
| 오류     | 오류 수와 비율. 0보다 크면 경고 색                    |
| 거부     | 거부 수. 허용목록 밖 툴 호출, 사용 중지된 커넥터 호출 |
| 소요시간 | 중앙값과 95번째 백분위                                |

### 호출 목록

| 열         | 내용                                              |
| ---------- | ------------------------------------------------- |
| 시각       | 날짜·시각(초까지). 최신순                         |
| 사용자     | 이메일. 사용자가 지워졌으면 "삭제된 사용자"       |
| 엔드포인트 | 이름. 엔드포인트가 지워졌으면 "삭제된 엔드포인트" |
| 툴 이름    | 코드 글꼴                                         |
| 결과       | 성공 / 오류 / 거부 배지                           |
| 소요시간   | ms. 1초 이상이면 강조                             |

- 행을 눌러도 펼쳐 볼 상세는 없다. 저장된 칸이 이것뿐이다.
- 사용자·엔드포인트 이름을 누르면 그 값으로 필터를 건다.

## 동작

- 50건씩 불러오고, 목록 끝의 "더 보기"로 다음을 불러온다(커서 방식, `at`과 `id` 기준).
- 사용자·엔드포인트가 지워져도 기록은 남는다. DB에서 해당 칸만 비워진다(`set null`).
- 오래된 기록은 보관 기간이 지나면 지운다. 화면 하단에 "N일이 지난 기록은 지워집니다"를 표시한다.

## 필요한 API (안)

| 메서드 | 경로                       | 내용                                                                           |
| ------ | -------------------------- | ------------------------------------------------------------------------------ |
| GET    | `/api/admin/audit`         | 필터(`from`, `to`, `userId`, `endpointId`, `result`, `tool`)와 `cursor`로 50건 |
| GET    | `/api/admin/audit/summary` | 같은 필터의 호출·오류·거부 수, 소요시간 중앙값·p95                             |

## 정할 것

- **보관 기간**: 기본 90일로 두고 환경변수(`AUDIT_RETENTION_DAYS`)로 바꿀 수 있게 할지 정한다.
- **커넥터 기준 보기**: 지금 기록에는 커넥터가 없고 엔드포인트만 있다. 엔드포인트가 지워지면 어느 커넥터 호출이었는지 알 수 없다. 사용자 목록(SCR-ADM-04)의 "커넥터 최근 호출"도 이 값이 필요하다. 감사 로그에 `connectorId`를 함께 저장할지 정한다.
- **사용자 본인 보기**: 사용자가 자기 엔드포인트의 최근 호출을 엔드포인트 상세에서 볼 수 있게 할지(v1 범위 밖으로 둘지) 정한다.
