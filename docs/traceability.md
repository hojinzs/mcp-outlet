# 요구사항 추적표 (v1)

[PRD v0.2](PRD.md)의 요구사항 ID마다 구현 위치와 그것을 확인하는 자동 테스트를 적는다. 경로는 레포 기준이고, gateway 경로의 앞 `apps/gateway/src/`는 줄여 `gw/`로 쓴다. 테스트는 `파일 › 테스트 이름`이다. 화면은 [화면 정의](screen-definitions/index.md)의 ID로 함께 적는다.

2026-11-05 기준 (M6). "자동 테스트 없음"은 실기 확인만 한 항목이고 근거를 함께 적는다.

## 남은 차이

spec-checker 대조(2026-11-05)에서 나온 것 중 이번에 고치지 않은 것과 그 근거다.

- **커넥터만 지우는 화면 없음** (F-CON-04): API(`DELETE /api/connectors/:id`)와 cascade 삭제는 있지만, 화면 정의 SCR-EP-03은 마지막 엔드포인트를 지울 때 커넥터를 함께 지우는 것만 정한다. 이때 체크를 풀면 엔드포인트 없는 커넥터가 남아 상한을 차지한다. 화면 정의를 정한 뒤 추가한다.
- **연결 중·재연결 필요 커넥터로 엔드포인트 생성** (F-CON-05): 서버는 기존 커넥터의 상태를 확인하지 않는다(사용 중지만 거부). 툴 캐시가 비어 있어 허용 툴 0개로만 만들어지고 화면 선택지에서는 빠진다. 재연결 콜백은 연결 테스트 없이 상태를 `ok`로 바꾼다.
- **화면의 "Authentik" 문구** (이식성): SCR-COM-03·SCR-ADM-04의 정의 문구를 그대로 썼다. IdP를 바꾸는 설치에서는 화면 정의부터 "IdP"로 고쳐야 한다.
- **업스트림 JSON 본문의 완료 시간** (네트워크): 응답 헤더까지만 `UPSTREAM_TIMEOUT_MS`를 적용한다. 본문 크기는 8MiB로 막았지만 천천히 흘려보내는 본문은 클라이언트가 끊을 때까지 연결을 잡는다.
